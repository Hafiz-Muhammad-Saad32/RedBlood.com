# RedBlood.com 🩸

A **Blood Donation and Finder Platform** built with **React.js** that helps users easily find blood donors and allows donors to register themselves.  
This project was developed as a **Midterm React.js Project** by **M.Saad & Suraish**.  

---

## 🚀 Features
- **Responsive Design** – Works perfectly on mobile, tablet, and desktop.  
- **Home Page** – Landing page with an interactive UI.  
- **About Page** – Information about the platform.  
- **Contact Page** – Get in touch with the team.  
- **Find Blood** – Search donors by **city** and **blood group** using a search bar.  
- **Registration** – Separate registration forms for:  
  - **Donors** (name, age, gender, blood group, city, contact, email).  
  - **Users** (name, city, blood group needed, contact, reason).  
- **Dynamic Blood Bottle UI** – Creative UI element that visually represents blood availability.  
- **API Integration (MockAPI)** – Donor and user data is fetched & stored via MockAPI.  
- **List Rendering** – Donors & Users displayed dynamically using `.map()`.  
- **Conditional Rendering** – Switch between donor & user forms.  
- **Props & State Management** – Smooth data handling between components.  
- **Routing** – Navigation between pages with React Router.  

---

## 🛠️ Technologies Used
- **React.js** (Functional Components, State, Props, Hooks)  
- **Tailwind CSS** (UI & Responsiveness)  
- **MockAPI** (Fake REST API for donors/users data)  
- **React Router** (Navigation between pages)

## ⚙️ Installation & Setup
1. Clone the repository:  
   ```bash
   git clone https://github.com/your-username/RedBlood.com.git
   ```
2. Navigate to project folder:  
   ```bash
   cd RedBlood.com
   ```
3. Install dependencies:  
   ```bash
   npm install
   ```
4. Run the project:  
   ```bash
   npm run dev
   ```
5. Open in browser:  
   ```
   http://localhost:5173
   ```
